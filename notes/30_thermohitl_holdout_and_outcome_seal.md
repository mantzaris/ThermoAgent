# Holdout and outcome-seal disposition

The prospective plan required a fresh topology, environment/LLM/operator seeds,
nominal and multiple disruption regimes, partitions, overload, delay, and
imperfect operators. Source, prompts, checkpoints, thresholds, statistics,
tables, and figures would have been frozen before the first episode, followed by
health-only monitoring and an outcome seal.

This process was never initiated. Gate 5 failed before validation, power-based
holdout design, or freeze. Consequently:

- holdout episodes: 0;
- holdout outputs opened: false;
- independent RL seeds: 0;
- non-inferiority/Pareto estimates: not run;
- selective reruns: none.

The guarded commands raise while `holdout_unlocked=false`. Future work must
create a new study version and genuinely unseen seeds; it may not unlock v3 by
editing the gate record.
