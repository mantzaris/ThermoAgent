# Future real-human study boundary

V3 contains no participant data. Simulated operator profiles cannot establish
actual attention, fatigue, workload, trust, usability, fairness, or safety.

The dashboard is technically prepared for a future institutionally approved
within-participant crossover comparison of local KPI, entropy-energy, and
entropy-energy-disagreement views. Prepared artifacts include a proposed
protocol, JSON trial schema, blocked-randomization template, response-time and
operator-action fields, view hashes, workload-questionnaire integration points,
and a power-analysis template.

Before recruitment, the responsible institution must determine IRB/ethics
requirements, finalize consent/withdrawal, accessibility, training, workload
limits, compensation, privacy, retention, failure handling, preregistration,
sample size, primary endpoint, exclusions, stopping rules, and analysis code.
Pseudonymous trial data and consent linkage must be separated. Oracle/evaluator
views must not be shown as feasible conditions.

Simulated development effects must not be used as if they were human pilot
effect sizes. A blinded actual-human pilot, if approved, would supply variance
for the power template. No fabricated questionnaire or participant result is
present.
