# V8 research question and scope

V8 asks whether locally scheduled, actually serialized belief sketches can
reduce fully counted communication while preserving distributed estimation and
the downstream performance of frozen decentralized autonomous policies.

The primary claim is communication-efficient distributed belief monitoring,
not selective-safety superiority and not human oversight. The entropy-specific
claim is conditional: it is eligible only if a frozen generalized-information
trigger beats the strongest matched-byte non-entropic scheduler in both
humanitarian logistics and defensive utility restoration.

V8 reuses the frozen V7 domain simulators as inherited code, but all V8 source,
seeds, protocols, manifests, and results are separate. V7 outputs will not be
regenerated. The sender may use only its private belief, private observation,
last actually transmitted state, received messages, and local clock. Global
latent state is evaluator-only.

The candidate scheduler family is fixed before pilot outcomes: always-on, none,
periodic, matched random, local KPI change, predictive-uncertainty change, L1
belief drift, age-of-information, V7 Shannon change, Jensen-Shannon drift,
Tsallis-spectrum drift, generalized-information score, and an offline oracle
upper bound. The primary payload-format comparison holds encoding fixed so that
only scheduling differs.

RunPod status at project start: the configured `runpod-thermo` SSH endpoint
refused the connection. No replacement Pod was created. Local CPU engineering
continues; GPU stages remain blocked until that same authorized Pod is running.
