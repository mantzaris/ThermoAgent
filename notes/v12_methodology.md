## What V10 and V11 establish

V10 provides an exact finite-state heat-bath reference. In the reciprocal
limit its stationary entropy production is numerical zero, and an
antisymmetric communication perturbation produces
`sigma(alpha)=C alpha^2+O(alpha^3)` with mean `C=0.1108861` nats per attempted
variable update in the frozen small model. It does **not** provide an LLM
network result: its final delivered-message pilot measured only binary
switching under weakly grounded messages and stopped prospectively.

V11 repaired that identification problem with typed evidence generated from a
known likelihood model and a continuous reported-belief endpoint. Its frozen
864-request qualification found a positive matched delivered-message effect on
reported log odds (`0.1343`, cluster-bootstrap 95% interval
`[0.0915, 0.1811]`) in both semantic framings. It failed its separate Bayesian
monotonicity and transition-diversity gates, including 92.24% right choices,
and therefore correctly stopped before its network experiment. V11 remains an
immutable qualification-stage no-go. V12 uses only the causal message-response
finding as developmental evidence that coupling can reach the model.

## Why V12 asks a different question

Calibration to a normative likelihood ratio, accurate reported probabilities,
and monotone response to stated reliability are not prerequisites for a
statistical mechanics of bounded-rational agents. Bias, persistence,
hysteresis, asymmetric response, and poor calibration are candidate microscopic
properties. V12 therefore uses realized categorical choices as its primary
state and asks how those empirical stochastic transitions organize in networks.
Self-reported confidence is a bounded secondary coordinate, not a transition
probability.

The primary Markovized prompt is rebuilt from the complete recorded local state
at every attempted update. It carries no hidden chat history. The secondary
regime exposes only a fixed three-entry private memory. If first-order closure
fails, V12 labels transition-current estimates as projected diagnostics and
uses block time-reversal KL as coarse-grained pathwise irreversibility rather
than claiming exact total entropy production.

## Right-state neutralization

The V11 imbalance is treated prospectively as an effective field. V12 uses
semantically symmetric `amber`/`cobalt` alternatives, random and exactly
balanced mappings of latent `+1`, randomized display order, balanced private
fields, balanced initial categorical states, symmetric action descriptions,
and matched prompt volume. Every response is decoded back to the latent spin
before analysis. The reciprocal-only engineering pilot may inspect validity,
latent occupancy, both transition directions, delivery, privacy, tokens, and
runtime. It is structurally unable to compare reciprocal and nonreciprocal
outcomes and does not compute currents or irreversibility.

## Network construction and isolation

V12 uses a degree-two ring and a fixed-degree-three modular graph. The modular
ensemble avoids V10's anomaly: V10 kept within-community probabilities fixed as
`N` grew, increasing mean degree from about 1.81 at `N=8` to 15.52 at `N=128`.
The unnormalized local field then saturated, acceptance collapsed, and paths
froze. Longer runs did not cure the problem; degree normalization restored
mixing. V12 fixes degree by construction.

For either topology, the delivery matrix is
`W(alpha)=W_s+alpha A_a`, where `W_s` is symmetric and row stochastic and
`A_a` is an antisymmetric, divergence-free cycle circulation. Thus support,
every node's weighted in/out degree, total message opportunities, payload
schema, and maximum payload size remain fixed while directional asymmetry
changes. `W` and `W^T` form orientation-reversed pairs. One valid agent update
creates exactly one model-chosen categorical signal packet; the graph, not a
central policy, chooses the permitted recipient using a common random tape.

## Agent and observable state

Agent `i` owns `(b_i,a_i,c_i,m_i,w_i)`: binary categorical belief and action,
bounded confidence/commitment, bounded explicit memory, and a local workload
coordinate. It also owns a private field, inbox, outbox, identity, role, and
typed tool authority. The primary transition projection is the exactly encoded
`(b,a)` configuration. The extended coordinates are retained for closure tests.
The scheduler selects only update opportunities, validates structure, moves
packets, and applies the chosen typed tool. A failed output after one repair is
an unchanged failed attempt, never a centrally substituted action.

One sweep is exactly `N` attempted random-sequential agent updates. Markov
entropy-production estimates are reported in nats per attempted update and,
after multiplication by `N`, nats per sweep. Block reversal divergences use the
same per-transition normalization. The independent inferential unit is the
entire matched graph-trajectory panel, never a time step, transition, message,
or token.

## Prospective execution rule

Only estimability and engineering integrity can change the design before
freeze. Once `protocol_frozen.yaml` is written, all predeclared reciprocal,
directed, transpose, control, small-network, collective, memory, relaxation,
and hysteresis panels run regardless of the sign of the scientific result.
Formal stopping is limited to corruption, systematic undefined outputs,
privacy or scheduler-substitution failure, unrecoverable hardware failure, or
the 24 single-GPU-hour ceiling.
