class for initial submission. This review copy therefore uses 12-point standard
LaTeX, embeds the final PDF figures in place, and keeps all figure text within
IOP's recommended 8--12 point final-size range. The final submission PDF is
built with:

```bash
scripts/build-statmech-v12-paper.sh
```

records on 18 August 2026. In particular, the V11 placeholder title for
