# DOET ablations

The seven trigger/direction/hysteresis candidates are evaluated prospectively
in validation and summarized as ablations. A 96-episode oracle/no-gossip/noise
signal extension is secondary: it runs only if measured validation plus the locked
holdout leaves room under the 35-hour cap. The complete extended design and
commands will be retained if those runs do not fit; no primary seed replication
is reduced to fund them.
