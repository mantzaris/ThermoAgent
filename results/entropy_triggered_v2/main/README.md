# V2 main/development comparisons

No separate post-selection exploratory main sweep is planned before the locked
holdout: adding one would consume the measured 35-GPU-hour budget and increase
researcher degrees of freedom. Real trigger selection is kept in `validation/`;
confirmatory comparisons are kept in `holdout_locked/`. If an extended
unlocked main sweep is later authorized, its outputs belong here and must be
labelled exploratory.
